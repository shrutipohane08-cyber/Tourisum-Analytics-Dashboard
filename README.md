🌴 Tourism Dashboard (Power BI)

📌 Project Overview

This project is an interactive Power BI Tourism Analytics Dashboard
developed to analyze travelers, customers, destinations, hotels,
bookings, revenue, and tourism performance. It provides a clear view of
key tourism KPIs, customer behavior, destination trends, and hotel
performance to support data-driven decision-making.

📈 Dashboard Features

Revenue analysis by customer region

Customer distribution by travel mode

Profit analysis by customer segment

Destination analysis by region and destination type

Travelers analysis by country

Revenue analysis by climate

Profit analysis by primary activity

Top 10 hotels by bookings

Revenue analysis by hotel facilities

Profit analysis by hotel opening year

Interactive filters for customer, destination, hotel, rating, cost,

Clear-all slicers for easy dashboard navigation

🔍 Key Insights

Nature is the most popular destination type based on traveler
activity.

UAE has the highest number of travelers among the displayed
countries.

Asia has the highest number of destinations among the displayed
regions.

Temperate climate destinations generate the highest revenue share.

Solo and Family customer segments contribute significant shares of
customers.

Large hotels represent the largest hotel-size category.

Royal Garden has the highest bookings among the displayed top
hotels.

Hotel facilities such as WiFi and Gym contribute significantly to
revenue.

Hotel profitability varies across different opening years.
